## 二、提炼的命题规律（可复用）

1. **封闭语料 × 变换模板 × 换挖空位**：一份语料可出 N 种题（写→选→填→情境），扩题靠变换不靠新增
2. **干扰项同源**：选择题干扰项取自同册/同单元语料（天然难度适配、无跨册错误）
3. **答案必须语料同源**：正确项 = 语料字段（词/诗句/读音），保证唯一确定答案
4. **难度三层**：基础（识记：写/选）、中等（语境运用）、挑战（多音字/换挖空位）——与 chinese-ai difficulty 字段对齐
5. **组合方式**：每课 = 字词基础（词语表 15 词 × 5 生成器）+ 古诗文积累（诗句 × 4 生成器）+ 文学常识（出处/作者）三线并行

## 三、迁移规则（教辅题型 → 生成器）

| 教辅题型 | 迁移生成器 | 语料依赖（LLM 富化一次性标注） |
|---|---|---|
| 古诗作者连线 | poem_author_choose | 无（author 课本同源） |
| 据义选词 | word_meaning_choose | 词语表词 meaning（215/215） |
| 选词填空 | word_context_choose | 词语表词 context 挖空句（215/215） |
| 词语归类找不同 | word_group_odd | 词语表词 tags 分类标签 |
| 多音字选读音 | polyphonic_choose | 写字表字 readings 读音组（17 个多音字） |
| 诗句情境运用 | poem_scene_choose | 诗句 scene_desc 情境（36/36） |

富化标注原则：LLM 只做**语料富化**（释义/读音/标签/情境），不做**编题**；答案恒取语料字段，判分确定性不变。标注版本 enrich_ver=llm-1.0，可整体重刷。

## 四、新题设计思路（未来扩展）

1. **近反义词选择**：词语表词补 antonym/synonym 标注（同富化管线）
2. **课文人物/情节选择**：需新增「课文句子/情节」语料 kind（课本 PDF 已 ingest，可从 spec 提取叙事段落）——一步到位支持课内阅读选择题
3. **标点/修辞判别**：同上依赖句子级语料
4. **年级扩展**：1-5 年级图谱题导入后，同管线补对应年级语料富化即可批量复制
5. **语料未覆盖的 32 条**：诗集课（古诗词三首）生字、园地杂句——待上游图谱补细粒度知识点后再挂
